# Audio Effect App

Application that allows the user to add a variety of different audio effects to .wav and .mp3 files

### Global
**Browse** select audio file to add effects to  
**Play** plays currently selected audio  
**Preview** plays a preview of audio with current effect and values  
**Select Save Folder** selects a directory to save file with audio effects applied  
**Filename** allows user to name their effected audio file as whatever they desire  
**Save** saves file to currently selected directory with the filename being (Filename).mp3  

### Distortion
**Fuzz**  
**Wavefold**  
**Bitcrush**  
**Chebyshev**  
**Gain** controls volume  
**Mix** controls amount of distortion applied  

### Resonance
**Lowpass**  
**Bandpass**  
**Cutoff Frequency** controls filtered frequencies  
**Resonance** controls intensity of resonance  
**Q Factor** controls range of frequencies  

### Vocoder
**Sawtooth**  
**Noise**  
**Number of Bands** controls amount of frequency bands  
**Frequency Range Low** controls lower frequency cutoff  
**Frequency Range High** controls upper frequency cutoff  
**Carrier Frequency** controls frequency of carrier audio  

### Phaser
**Phaser Rate** controls phaser LFO rate  
**Depth** controls depth of phaser notches  
**Stages** control number of all-pass filters  
**Wet Mix** controls the phaser wet/dry ratio  
**Mix** controls amount of phaser effect applied  

### Flanger
**Flanger Rate** controls flanger LFO rate  
**Delay Base** controls base delay time (seconds)  
**Delay Depth** controls delay modulation (seconds)  
**Mix** controls amount of flanger effect applied  

### Chorus
**Pitch Modulation Amount** controls the variance in pitch  
**Speed** controls pitch modulation speed  
**Number of Clones** controls number of voices  
**Delay** controls base delay (seconds)  
**Mix** controls volume of added voices  

### Delay
**Digital**  
**Analog**  
**Delay Time** controls delay time (seconds)  
**Feedback** controls feedback amount  
**Low-pass Cutoff** controls low-pass filter  
**Flutter Depth** controls flutter modulation  
**Pitch Drift Depth** controls variance in pitch drift  
**Drive** controls intensity of delayed audio  
**Mix** controls volume of delayed audio  

### Glitch
**Number of Segments** controls how many parts the audio will be broken into  
**Intensity** controls how much each random glitch effect will be applied  
**Loop Length** controls how long each loop will be for the glitched audio  

### Saturation
**Number of Crossovers** controls how many frequency ranges you can select  
**Crossover** controls frequencies that the drives will effect (Crossovers must be in ascending order)  
**Drive** controls saturation effect in their respective crossover range
